# h44 notes, s1-delivery

- beta: no letter allowed, so the early-users circle had to be told with people shapes, a ticket, stones and a half-hatched disc.
- release / changelog: version numbers cannot be drawn without text, so tag, tray-and-arrow and diff chips stand in.
- log vs ledger vs record: three near-neighbours in the ruled-paper family; I split them by object (chip rows, coin, index card, tablet, accordion strip, stamp).
- flow and test: abstract states; weakest weird drawings (lemniscate, dial) lean on the classic metaphor.
- solids with several carved holes (changelog, journal, ledger, record weird) are the fragile ones at 24px.
