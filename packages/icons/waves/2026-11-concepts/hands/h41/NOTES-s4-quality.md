# h41 · s4-quality notes

- quality-assurance, verification, criterion, resolved: all want a tick. I gave each a different carrier (clipboard, shield, ticked box, circle; stamp, double tick, touchstone, plumb bob) so the four ideas don't collapse into one.
- parity: "the same on every platform" has no object. I used two phones and an equals sign, waves in step, three equal stones and a Venn whose shared centre is the mark.
- observability and monitoring overlap (eye/window vs screen/radar). I kept signals inside for observability and waiting/alarm for monitoring.
- efficiency: a leaf is cliché, and the direct path vs the wandering one gets busy at 24 units.
- reliability weird: a circle drawn over itself twice fails the checker (even-odd hides the inside), so it became one loop with a second partial pass.
- Small hosts (box, vial, bob): a 2-unit dot plus stroke fills almost all of the interior, so the marked versions there read heavy.
