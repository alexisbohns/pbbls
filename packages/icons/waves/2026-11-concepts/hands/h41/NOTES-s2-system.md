# h41 · s2-system notes

- node, node-add, node-new, node-remove: four concepts on one circle. They differ only by what sits beside the node (a plus, a minus, rays, a cut), and the pebbles idea pairs add and remove as a stone dropped onto a cairn and lifted off it.
- branch, fork, merge, git: the standard git diagrams look alike. Merge needed an arrow to show which way it flows. Fork leans on the signpost and the dinner fork, git on a branch that leaves and comes back.
- api: a contract has no object of its own. Angle brackets, a plug in its socket and a tin-can phone each show only part of it.
- agentic: no faces and no letters, so "acting on its own" is a sparkle, a path walked to a flag, and a self-closing loop.
- Fills cannot carve anything, so a solid hides any detail drawn inside its body (database rows, server slots, the arch's keystone). Those solids show only the silhouette.
