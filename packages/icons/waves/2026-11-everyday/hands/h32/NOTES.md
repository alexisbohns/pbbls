# Hand h32: Quiet Ledger

Owns all 124 figures, five versions each (620 pairs, 13 batches, all passing check.py).
Method: each stone is a six-point loop that closes by overlap; lines lean a little; an active twin lights one stone, or
carves a mark out of a filled body (evenodd, stroke none) and drops the base stroke of that mark underneath.

Families kept in one vocabulary per version number:
- visibility trio: v1 people, v2 eye, v3 door, v4 rings, v5 cloche
- appearance trio: v1 sun/moon/split stone, v2 horizon, v3 shining pebble, v4 toggle, v5 window
- error family: v1 glyph + mark, v2 stones, v3 cloud/rope/sheet, v4 bar/plug/ghost, v5 hole/hook/paper plane
- alert / warning / danger: v1 ring / triangle / octagon, v3 road signs, v4 a stone cracking more and more, v5 one, two, three strokes

Hardest: alert/warning/danger (three real escalations that stay apart at 24 pt), sound/audio/waveform/mute/microphone
(five figures, one vocabulary of lines), rock/boulder (scale without a second object), page-gone (an absence has to be drawn),
language (kept clear of public by using speech, not a globe; the globe went to url).
Weakest drawings I would redo first: stepping-stone v1/v3, jellyfish v4, boulder v2/v3, search v4, appearance-device v2.
